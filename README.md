# ⚙️ AI-Based Predictive Maintenance and Machine Health Monitoring System

## 📌 Project Overview

This project is an AI-powered Predictive Maintenance and Machine Health Monitoring System developed as an NTCC project for B.Tech CSE (AI & Data Science).

The system uses Machine Learning techniques to analyze machine operating parameters and predict the likelihood of machine failure before it occurs. The goal is to reduce unexpected breakdowns, improve maintenance planning, and increase machine reliability.

The model is trained using the AI4I 2020 Predictive Maintenance Dataset and deployed through an interactive Streamlit web application.

---
